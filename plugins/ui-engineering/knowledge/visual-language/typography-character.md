# Typography character

Define the product voice, hierarchy contrast, display/body relationship, data/label behavior, line measure and responsive adjustment. Choose type because it supports audience and content, not because it is currently fashionable or because avoiding a fashionable face became its own default. Preserve a coherent existing type voice unless a documented direction or usability issue requires change.

The type archetype, families, pairing and scale are selected by [Typography Intelligence](../../skills/typography/README.md) and recorded in `DESIGN-SYSTEM.md`. This grammar dimension records only how that character renders across components and its approved exceptions; do not re-decide families here.
