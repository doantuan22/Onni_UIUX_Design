# Typography

Define a compact hierarchy with display, headings, body sizes, label/caption, and button text as needed. Each role specifies family, size, weight, line height, and letter spacing. Prioritize readable hierarchy over adding fonts or weights. Verify hierarchy, wrapping, and contrast across selected viewports.
