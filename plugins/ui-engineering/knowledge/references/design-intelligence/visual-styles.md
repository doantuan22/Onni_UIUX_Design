# Visual style patterns

Select a style only when it supports brand personality, content, and task. Describe surface treatment, type character, contrast, imagery, and motion as a coherent language. Reject borrowed style elements that add noise or create an indistinguishable default AI aesthetic. Curated styles are defined as archetypes in [design-inspiration/archetypes.md](../../../skills/design-inspiration/archetypes.md); visual languages (swiss, glassmorphism, calm futurism, …) are catalogued in [knowledge/styles](../../domains/styles/README.md); this file does not keep a separate style catalog.
