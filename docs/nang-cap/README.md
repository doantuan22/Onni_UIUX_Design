# Bộ tài liệu nâng cấp plugin ui-ux-design

Bộ tài liệu (tiếng Việt) tổng kết đợt nâng cấp giao diện của plugin **ui-ux-design** — giúp AI coding hiểu cấu trúc
frontend, nâng cấp bố cục và hiệu ứng thật sự, thoát khỏi phong cách "giao diện AI", và chứng minh kết quả bằng ảnh
chụp render thật.

| Tài liệu | Nội dung |
|---|---|
| [1. Những gì đã nâng cấp](01-nhung-gi-da-nang-cap.md) | Dòng thời gian các phiên bản và PR, vấn đề ban đầu, 4 bước nâng cấp (ambition, bản đồ UI, code recipe, vòng review ảnh chụp), quy trình hoàn chỉnh, kết quả trước/sau và cách kiểm chứng |
| [2. Kế hoạch chưa thực hiện](02-ke-hoach-chua-thuc-hien.md) | Các mục đã đề xuất nhưng chưa làm hoặc mới làm một phần, lý do, mức ưu tiên và công sức ước tính |
| [3. Hướng phát triển](03-huong-phat-trien.md) | Lộ trình ngắn, trung và dài hạn, chỉ số theo dõi, rủi ro và cách giảm |
